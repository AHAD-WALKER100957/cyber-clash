the operation

Four rounds. Score carries forward from the first question to the last flag.

No team is eliminated between rounds — every point earned in Round 1 still counts when the final flag is submitted in Round 4. Difficulty climbs each round; so does the noise in the room.

ROUND 01

Cyber Quiz

Rapid-fire multiple choice on networking, malware, authentication and core security fundamentals. Thirty seconds a question — guess if you must, there's no penalty.

15 min/80 pts
ROUND 02

Crypto Crack

Five progressive ciphers — Caesar, Base64, hex, Morse, Vigenère. Cracking one hands you the key to the next. Pen and paper only.

25 min/25 pts
ROUND 03

Bug & Vulnerability Hunt

Three real-world-style code snippets. Spot the flaw, explain the risk, write the fix. This is where genuine security instinct separates the field.

30 min/24 pts
ROUND 04

Cyber Detective / CTF

A four-flag capture-the-flag: OSINT, steganography, log analysis, file forensics. Expect live bulletins from HQ mid-round. Nobody sits this one out quietly.

35 min/50 pts
